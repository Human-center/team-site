How this canvas works

A bitmap you redraw every frame

The About panel is not a video or an image. It is an HTML <canvas> — a 2D drawing surface. The script paints dots and lines 60 times a second.

  1. 01

    Get a 2D context

    canvas.getContext("2d") is the paint API. CSS sizes the box; we set canvas.width / height to CSS size × devicePixelRatio so it stays sharp on retina screens.

  2. 02

    Particles are just data

    Each node is {x, y, vx, vy}. Every frame we add velocity, bounce off the edges, and ease toward the pointer (magnetism). Then we draw a radial-gradient glow and a solid core.

  3. 03

    Link what is close

    If two particles are nearer than a radius, we stroke a line. Opacity fades with distance so the graph reads as a network, not a scribble. Pause the loop when the canvas is off-screen.
